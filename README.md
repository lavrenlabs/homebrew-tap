# homebrew-tap

Homebrew tap for [Diaspar](https://diaspar.dev) — the agent-native memory system with an MCP interface.

## Install

```bash
brew install --cask lavrenlabs/tap/diaspar
```

## Update

```bash
brew upgrade --cask diaspar
```

## About

This tap is auto-updated by [GoReleaser](https://goreleaser.com) on every Diaspar release.
The cask in `Casks/diaspar.rb` is generated automatically — do not edit it by hand.

Binary releases, checksums, SBOMs, and release evidence live at
[lavrenlabs/diaspar-releases](https://github.com/lavrenlabs/diaspar-releases).
Documentation: [diaspar.dev](https://diaspar.dev).
